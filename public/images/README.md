# Public images

- `profile.jpg`   → your hero portrait (the site auto-detects it; 4:5 ratio looks best)
- `projects/NAME.jpg` → project thumbnails (16:10); set `image: "/images/projects/NAME.jpg"` in content/projects.ts

Only PUBLIC images live here. Personal/private photos belong in the
private gallery (they are stored server-side and require login) —
never put them in this folder.
